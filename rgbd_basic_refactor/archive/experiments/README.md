# Archived experiments

Historical `compare*.py`, `TM5.py`, `TM6.py` and RGB Tsetlin variants remain in the Git history of the original repository. They are intentionally not copied into the runnable package because they duplicate the new modules and can accidentally be used as production entry points.

The final comparison uses the grayscale Tsetlin configuration. Copy an old file here only when reproducing a named historical experiment.
